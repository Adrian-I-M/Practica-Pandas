Práctica Pandas

Programa en Python para cruzar, limpiar y analizar datos de alumnos y sus notas utilizando la librería Pandas.

Instrucciones de ejecución

Activa el entorno virtual desde tu terminal:
.\.venv\Scripts\activate

Instala las dependencias necesarias:
python -m pip install -r requirements.txt

Inicia la aplicación usando el menú interactivo:
python main.py

Análisis del gráfico

El gráfico analiza el rendimiento de los alumnos que tienen las tres calificaciones completas. Se observa una tendencia ascendente clara en las notas, siendo la Actividad 3 la que presenta la nota media más alta de todo el conjunto.
